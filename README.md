## 核心设计决策（已确定）

1. **定位**：不做"智能客服"，做"客诉闭环 Agent"——内部管理闭环 + 归因 + 推动改进
2. **主视角**：**客户体验**（而非内部效率）——确定性 + 不被踢皮球 + 有交代
3. **五字主流程**：接 → 判 → 分 → 回 → 追（每一步都有"客户感知"维度）
4. **对齐灵核**：用"数智员工""岗位级""721理论""归因打标"等公司语言
5. **差异化**：归因打标（首次/反复）+ 8D 自动生成 + 客户进度看板

## 关键情报速览

- 灵核数智已在做客诉闭环方向（陈弘旋公开讲过）
- 陈弘旋"721理论"：70% 大模型 + 10% 历史数据 + 20% 人机交互沉淀
- 产品三大模块：派派市场 / 记记空间 / 问问中心
- 入口级 Agent 优先落地（客诉是入口级场景）
